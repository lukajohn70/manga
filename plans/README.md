## Recommended Execution Order

1. **Foundations First:**
   * **Plan 008:** Declare core motion tokens (`--ease-out`, `--duration-ui`) in `globals.css`.
   * **Plan 004:** Establish humanized `prefers-reduced-motion` and touch pointer safety.
2. **High-Severity Performance & Feel Fixes:**
   * **Plan 001:** Eliminate layout reflow in `flyAnimations.ts` (switch to pure GPU transforms).
   * **Plan 002:** Fix instantaneous modal unmounting in `BuyBoxModal.tsx`.
   * **Plan 003:** Remove keyboard squishing on buttons and tighten release spring.
3. **Storefront Interactive Polish:**
   * **Plan 007:** Strip unbounded `transition-all` from checkout and cards.
   * **Plan 005:** Tune product card hover duration down to 200ms.
   * **Plan 006:** Add anchored origin scaling to the account dropdown.
4. **Delight & Additive Enhancements:**
   * **Plan 009:** Sliding category pill indicator via `layoutId`.
   * **Plan 010:** Catalog grid stagger entrance.
   * **Plan 011:** Install Sonner for tactile, gestural toast feedback.
   * **Plan 012:** Elastic cart badge count pop.
